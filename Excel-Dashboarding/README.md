# 📈 Excel Dashboard Practices

Once data is cleaned, it requires an engine and an interface. The projects in this folder focus on building automated data engines and intuitive, stakeholder-ready interactive dashboards natively in Excel Web.

## Core Mechanics Practiced Here
*   **The Engine Room:** Building robust Pivot Tables and Pivot Charts to aggregate complex datasets.
*   **The Matchmakers:** Utilizing `XLOOKUP` and `INDEX+MATCH` to bridge mapping tables dynamically.
*   **The Storytellers:** Connecting interactive Slicers across multiple data sources to create seamless filtering.

Each folder contains completed projects following the full **3-Tab Architecture** (`Raw_Data`, `Clean_Data`, `Dashboard_Engine`), culminating in the final Dashboard canvas.
